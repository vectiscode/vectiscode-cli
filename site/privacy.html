Privacy

Short version: vectiscode looks at your logs on your own computer and sends nothing anywhere.

The tool

  • It reads the session logs that Claude Code and Codex already keep on your computer (~/.claude and ~/.codex, or the folders you point it to).
  • It only reads them. It never changes, moves or deletes a file.
  • It makes no network calls. There is no account, no telemetry and no crash reporting.
  • The report is printed in your terminal and nowhere else.

Running npx vectiscode downloads the package from the npm registry, which is covered by npm's privacy policy. The source is on GitHub if you want to check.

This website

  • No cookies, no analytics, no trackers and no forms.
  • Fonts and files are served from this domain only.
  • The site is hosted on Cloudflare Pages. Like any web host, Cloudflare processes basic request data such as IP addresses to deliver and protect the site. See Cloudflare's privacy policy.
